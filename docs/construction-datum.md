# 施工基准（Construction datum）

施工基准是每个 `Level` 可选的一条数值水平线，供施工定位与高度换算使用。底部「建造」第二行的「施工基准」工具在左侧常驻作者栏编辑它；默认标签为 H01，作用范围是本层所有墙面。作者只需填写两项毫米数值：基线离毛坯地面高度、水平基线离完成面高度。第二项留空表示完成面未定义；显式 `0` 表示完成面与水平基线等高。完成面标高等于水平基线标高减去第二项，地面完成厚度是该结果与原始参考的差。只读结果同步显示基线离完成面的高度，未定义时显示“待设置”。模型墙面上以深蓝灰色细线表示，按真实墙厚位于两侧表面，受墙体遮挡，并在基线高度穿过的门窗洞口中断，不绘制跨洞连接线。直墙两侧基线的起止分别采用与渲染墙体一致的斜接面边界，在墙角按实际表面棱收口，不以中心线端点截断；洞口位置仍按源墙坐标裁剪。文字标记以约 48 mm 的固定物理字高贴在对应墙面外侧，沿墙体切线旋转，不随相机转向或缩放，并受墙体深度遮挡；使用本机 Canvas 字体，不依赖网络字体。

原始参考由系统自动解析：只有一块有效本层 Slab 时采用其顶面；多块 Slab 顶标高相同时按稳定 ID 选择一个来源。若多块 Slab 的顶标高不同，作者点“选参考地面”后直接点击本层楼板顶面。模型没有有效楼板时，不能新建以虚构地面为依据的基线；已保存的 Level 基准仍可编辑并原样保留。创建时保存来源 Slab 的稳定节点 ID 和实际顶面标高。编辑既有基线时，原始参考及其未知字段完整保留；只有显式选择另一块楼板时才更新来源。数值 `heightAboveRawMm` 表示基线高于参考点的毫米数；规范 `elevationMm` 必须等于 `rawReference.elevationMm + heightAboveRawMm`。基线高度必填，`0` 有效。

保存的完成面偏移仍以同一个原始参考点为基准；作者输入基线离完成面的高度，再换算 `finishedFloorOffsetMm = heightAboveRawMm - 基线离完成面高度`。第二项留空时，墙面文字显示“待设置”，图纸高度继续采用现存物理模型标高依据，不把未定义完成面当作 0。存储偏移 `0 mm` 是有效完成面，不与留空混淆。墙面标注格式为 `H01 水平基线离完成面高度 1300 mm`；其换算为 `heightAboveRawMm - finishedFloorOffsetMm`。例如参考地面高于楼层基准 50 mm、基线高于参考 1350 mm、完成厚度为 50 mm，则基线离完成面 1300 mm。

局部完成面只在选中 Zone 的属性中编辑，输入正负高低差；正值表示高于本层完成面，负值表示低于本层完成面。局部值是相对本层通用完成面的偏移，不是替换值；例如通用完成面高于原始参考 50 mm，Zone 偏移 -20 mm，则该 Zone 完成面为 30 mm，基线离完成面 1320 mm。Zone 外使用通用完成面；多个 Zone 重叠时区域判定不唯一，不套用局部偏移。不会把整层 Slab 推断为房间，也不会将整层完成面自动应用到跨多个区域的 Slab。

在施工基准工具下点击 Zone 可直接编辑本区完成面偏移；普通选择模式下点击 Zone 仍按正常建筑对象选择，属性面板提供施工基准区域设置入口。点击水平线选中全局 Level 基准。单独修改全局线高时，基线离完成面高度随之换算，已确认完成面标高保持不变；线及设备相对 H 基线的尺寸更新。设备和完成面均不变，因此相对完成面的 H 高度不变。已有设备世界坐标、设备端口、路线和连接均保持原位。修改 Zone 完成面只更新该区域的完成面标注与派生安装高度，不移动设备。

选中非地面设备时，3D 显示设备底边至当前 H 基线的局部测量见证；设备定位标记以约 34 mm 固定物理字高置于浅色近不透明小底框中，贴在实际宿主安装面并受实体遮挡。墙面数字沿墙方向排字、两侧不镜像；非墙宿主按其安装面 basis 排字。真实尺寸见证保持原端点，文字框单独投影到安装面。H01 全局标签继续使用约 48 mm 固定物理字高的无底框文字。横向参考数值只在对应尺寸线上显示一次，短标签不遮挡点位或墙角；展示投影不修改实际测量 witness 和编辑 endpoints。属性主区使用“下边缘相对水平基线 H01”与中心到左右垂直基准线净距。完成面已定义时，下边缘至完成地面的派生高度只读显示；原始楼板顶/模型楼层距离与到墙顶的实体净距收于折叠“实体净距”。未配置基准时可继续编辑垂直实体距离，并明确使用楼板顶面或模型楼层基准名称。底边编辑使用设备现有宿主和定位约束；端口已有线路时仍锁定移动，遵循已有连接规则。改变基准不会通过这一属性反向移动设备。几何移动完成后，H 高度表再按新设备底边与明确完成面重新计算。旧楼板地插在明确对齐完成面之前保持原世界位置。地面点位不显示 H01 竖直偏差或“下缘至楼板顶面”字段，主高度依据改为上口相对完成面的实际偏差。

安装高度表和 2D 高度注记共享完成面解析。基准完成面已定义时，非地面设备下边缘相对完成面测量；明确完成面挂载的地面设备则按上口相对当前完成面测量。完成面未定义时，地面挂载的图纸读数明确退回上口相对模型地面并标为待确认，不能从过期节点快照取旧完成面。输出的证据来源包括设备、基准、基准的原始 Slab/Level 参考，以及实际使用局部覆盖时的 Zone ID。Schedule 的 `sourceIds` 仍只表示计数成员；`evidenceSourceIds` 单独保留测量证据，避免改变数量、分组和变体语义。没有已定义完成面时维持已有物理楼板顶/楼层基准测量，并保留其 derived basis 与假设。

## Project 4.0 归属

新元数据只写入拥有该基准的 `Level.constructionDatums`，不更改 Slab、Wall、Zone 或其他导入建筑节点。字段可选，因此旧 Level 不带基准时可以原样导入导出。每层最多一条当前共享基准；保存校验会验证所有者 Level、来源 Slab 与 Zone 的同层关系、稳定 ID、数值类型以及规范标高公式。编辑现存元数据时保留未知 future fields；确认取消完成面会真正删除已知 `finishedFloorOffsetMm` 字段而不复活旧值。该归属与不自动移动设备的取舍记录在 [ADR 0013](adr/0013-level-construction-datums-and-finished-floor.md)。

可接受的 raw reference 类型是 `slab-top` 和显式 `level-base`。本实现的局部区域只使用显式 Zone；房间空间或任意几何表面需未来以清晰稳定的区域对象接入。导入未知建筑节点仍只读。施工线是显示与测量依据，不是新的建筑实体或手工高度线。

## 完成面定位与地面点位

已确认完成面时，3D 自动按本层真实 Slab 范围生成完成面定位面；保留 Slab 孔洞，按唯一明确 Zone 差值分区，楼板范围重叠或缺少唯一楼板来源时不作为放置依据。它可见、可选择并可吸附，墙上同步显示与水平基线样式一致的完成面高度线，贴墙标注“地面完成面”，跟随明确 Zone 高低差，按该高度的门窗洞口裁剪；未定义完成面时不显示。该定位面不代表已建砂浆或面层厚度。未定义完成面时不生成虚构地面。

在完成面放置支持地面安装的底盒时，默认上口齐平、盒体向下埋入；也可明确设置上口高于或低于完成面的偏差。已有点位通过“对齐完成面”明确移动，连接中的点位保持锁定。修改完成面不自动移动任何点位，实际偏差按当前上口世界坐标减去当前完成面重新计算；挂载保存的放置偏差不是对当前齐平状态的承诺。

地面点位的四向尺寸从中心量取，面板使用“中心至 G01 基准线”等编号表达。编号按相同楼层的稳定墙面来源与实际面侧生成，面板和场景共用同一参考解析；相同参考不为每个设备重复编号。选中时高亮对应墙面与完成面的交线或明确洞口边参考，并在线旁显示编号。数字框贴在定位面上，H01 不作为地面点位施工时的竖直量尺。墙面垂直参考线沿有效墙高通长显示，墙角使用实际墙面交界棱；即使命中宿主墙自身端部，也按该安装侧的真实斜接边界定位，不退回墙中心线端点。墙角距离读数、输入距离后的移动、尺寸端点与高亮线使用同一实体边界。洞口按真实实体范围处理。

完成面几何由已有元数据派生，Project JSON 不增加另一份地面网格。设备的 `mount.kind = "finished-floor"` 保存 `levelId`、`datumId`、`sourceSlabId`、可选 `regionId` 与最近明确定位的 `topOffsetMm`；未知挂载字段和节点身份仍保留。来源必须真实且同层，图纸证据保留设备、基准、源楼板及实际使用的区域 ID。该语义见 [ADR 0015](adr/0015-derived-finished-floor-placement.md)。
