# Pascal JSON 只读 3D 查看器

## 边界

3D Viewer 是一个本地展示层。它从 `Parsed.nodes`、根节点、材质、集合与插件信息制作 JSON 深拷贝，并由独立适配渲染层消费该副本。唯一例外是文档化的 Demo `beam` 扩展：3D 梁工具可通过统一工作区事务写入新的 Beam 项目节点；其他导入 Pascal 节点仍只读。为保证大型家具场景可交互，画布使用轻量 WebGL 几何展示，不启动 Pascal 发布包中会造成卡顿的 WebGPU 后处理链路。相机、图层、隐藏与选择状态不会修改导入 JSON、Parser 输出或 Evaluation Handoff。

G1/G2/G3/S1 继续只消费原有二维 Parser、几何和 Handoff。评价卡片定位会切回 2D；3D 中看到的剖切、隐藏、爆炸、单层与漫游画面均不是评价证据。

有效 Demo Beam 的底面、侧面和端面可作为施工管线宿主；顶面与 Ceiling 相接，不可选择。梁面路由保持明装且不产生槽。渲染器之外的解析碰撞检查仍会把有效梁实体作为障碍物，因此悬空和世界轴向管段进入梁体也会显示红色冲突并阻止提交；无效导入梁不会成为宿主或障碍物。

所有当前设备类型也可选择有效 Beam 的底面、侧面和端面；显示几何和端口按该面法线与基准定向，顶面不会成为点位候选。编辑梁不会拖动设备或管线：仍接触该面的关系保留，失效关系会在同一工作区事务中清除为未宿主。仍承载设备的梁会拒绝删除并显示设备身份；未承载时仅清理该梁穿孔，不改写剩余管线坐标。这些可视化记录不构成荷载、配筋、开孔安全区、规范或结构审批结论。

## 数据诚实性与降级

- 仅传递源 JSON 已有的节点和变换；根节点缺失时仅从 `parentId` 为空的节点推导，并显示诊断。
- `slab.elevation` 在 Pascal 中表示从本层 Y=0 向上的楼板厚度；3D 按该厚度挤出楼板，并把位于其 polygon 内、普通落地家具的源 Y 坐标放在楼板顶面之上。墙面/天花附着对象不套用该抬升。
- `roof` / `roof-segment` 缺失时显示“当前文件无屋顶数据”，不得补造屋顶。
- 未承诺的第三方节点保留在输入中并显示信息诊断。
- 不加载 GLB；家具统一以由源 `asset.dimensions × item.scale` 得出的尺寸占位展示，避免在一个场景中并发请求大量模型。

## 展示控制

支持外观、室内、地板、天花及六个镜头角度预设；透视/正交投影；叠放、爆炸、单层楼层模式；完整、剖开、半透明、隐藏墙体模式；墙、楼板、天花、梁、屋顶、门窗、家具、Zone 图层开关。梁层默认开启；创建说明见 [Demo Beam authoring](beam-authoring.md)。默认使用不锁定光标的自由相机：鼠标旋转、右键平移、滚轮缩放。所有展示控制只保存在当前 React 会话。
