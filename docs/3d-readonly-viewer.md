# Pascal JSON 只读 3D 查看器

## 边界

3D Viewer 是一个本地、只读的展示层。它从 `Parsed.nodes`、根节点、材质、集合与插件信息制作 JSON 深拷贝，并由独立适配渲染层消费该副本。为保证大型家具场景可交互，画布使用轻量 WebGL 几何展示，不启动 Pascal 发布包中会造成卡顿的 WebGPU 后处理链路。相机、图层、隐藏与选择状态不会修改导入 JSON、Parser 输出或 Evaluation Handoff。

G1/G2/G3/S1 继续只消费原有二维 Parser、几何和 Handoff。评价卡片定位会切回 2D；3D 中看到的剖切、隐藏、爆炸、单层与漫游画面均不是评价证据。

## 数据诚实性与降级

- 仅传递源 JSON 已有的节点和变换；根节点缺失时仅从 `parentId` 为空的节点推导，并显示诊断。
- `slab.elevation` 在 Pascal 中表示从本层 Y=0 向上的楼板厚度；3D 按该厚度挤出楼板，并把位于其 polygon 内、普通落地家具的源 Y 坐标放在楼板顶面之上。墙面/天花附着对象不套用该抬升。
- `roof` / `roof-segment` 缺失时显示“当前文件无屋顶数据”，不得补造屋顶。
- 未承诺的第三方节点保留在输入中并显示信息诊断。
- 不加载 GLB；家具统一以由源 `asset.dimensions × item.scale` 得出的尺寸占位展示，避免在一个场景中并发请求大量模型。

## 展示控制

支持外观、室内、地板、天花及六个镜头角度预设；透视/正交投影；叠放、爆炸、单层楼层模式；完整、剖开、半透明、隐藏墙体模式；墙、楼板、天花、屋顶、门窗、家具、Zone 图层开关。默认使用不锁定光标的自由相机：鼠标旋转、右键平移、滚轮缩放。所有控制只保存在当前 React 会话。
