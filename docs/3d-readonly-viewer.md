# Pascal JSON 只读 3D 查看器

## 边界

3D Viewer 是一个本地展示层。它从 `Parsed.nodes`、根节点、材质、集合与插件信息制作 JSON 深拷贝，并由独立适配渲染层消费该副本。唯一例外是文档化的 Demo `beam` 扩展：3D 梁工具可通过统一工作区事务写入新的 Beam 项目节点；其他导入 Pascal 节点仍只读。为保证大型家具场景可交互，画布使用轻量 WebGL 几何展示，不启动 Pascal 发布包中会造成卡顿的 WebGPU 后处理链路。相机、图层、隐藏与选择状态不会修改导入 JSON 或 Parser 输出。

施工管线、设备、槽孔和施工图信息保存在统一 `schemaVersion: "4.0"` Project JSON 的系统及 Drawing 节点中；编辑器内部仍用 Overlay 适配结构；3D Viewer 只读取 Pascal 建筑底图和 Overlay，不能把展示状态写回任一数据源。3D 中看到的剖切、隐藏、爆炸、单层与漫游画面均只是当前会话的展示状态。强电箱和弱电箱都在设备下沿、上沿各横向排列 10 个物理孔；强电箱的插座与照明系统共用这 20 个孔，任一系统占用后另一系统不能重复占用，弱电箱的 20 个孔供网络线路使用。新建箱体的首排孔位沿用横向和上下排定位，但其管线中心落在安装宿主表面，和普通墙面管线保持同一敷设深度；额外端口才沿宿主法线进入后续排。这些是 Overlay 中的真实端口位置，不会为新增管线挤压既有管线。按 `L` 进入通用画管起点选择时，绿色设备端口、86 底盒孔位、开放管端、HVAC 送/回风端口和温控器控制端显示所有当前可起画候选；点击后路线自动采用该端口的系统，左侧 Builder 固定栏切换到对应系统。强电箱的插座与照明线路共用物理孔，仍由左侧当前系统决定显示红色还是蓝色孔位。单独点击 Builder 画管卡时，系统锁定到卡片所属系统，绿色提示只展示该卡可用的来源。箱体本身不会回退选择首孔，只有单击具体孔位才会起管。路线已起画时，悬停目标设备显示端口辅助对齐或连接提示，左键点击端口或设备本体均按最近兼容开放端口处理；点击具体端口孔时，以该孔的实际位置选择当前正交方向，设备本体命中仍按指针命中位置选择方向。辅助对齐只确认下一落点，不连接设备。从 86 底盒出发的路线也可连接目标设备端口。已接源线路的开放管端在画管模式显示可点击绿点：尚未起画时点击它可从该端续画；已有同系统草稿时点击它可确认辅助对齐点，仍需继续绘制，不会暗中合并两条管道。

普通点位（包括灯位接线盒）的 3D 定位通常从点位中心量取；墙面 86 底盒向下离地尺寸从盒底量起。墙面点位的左右方向沿墙体轴线：先遇到同墙同高度的另一点位时量到对方中心，否则量到同层首个实体墙面、洞口边或墙端；相接墙以实际相交的房间侧墙面为终点，不使用相接墙轴线。墙面 86 底盒的完成地面见证优先取点位正下方的楼板顶面，无楼板时回退到楼层基准。属性框的墙面左右标签按当前相机的屏幕方向显示，并根据见证点区分另一点位中心、洞口边、墙边、墙顶和地面。梁面、天花及楼板点位沿安装面两个轴量到首个实体表面；同一非墙宿主上的其他点位若与尺寸轴的横向偏差不超过 100 mm，也可作为中心到中心目标。此时尺寸值使用两点实际中心距离，尺寸线端落在另一点中心；连接射线若先碰到实体，实体交点优先。编辑该值时沿当前轴调整，横向偏差保持不变；小于横向偏差的输入无效。参考平面点位另有一条向下尺寸，止于首个实体表面。2D 与 3D 共用有限实体三角面的射线求交、默认墙厚和设备外壳半尺寸；3D 负责空间标注，2D 负责尺寸链布局，但两者保留相同的实体 witness、数值、basis、assumptions、confidence 和 source IDs。墙面射线略入墙厚后再求交，避免沿墙面共面导致漏掉墙端和洞口边。非墙宿主的定位尺寸线及端点为避免与宿主共面而沿宿主法线抬高 25 mm，数值仍以原始未偏移的物理见证计算。点位尺寸标签按稳定顺序分配不同屏幕位置，避免四向标签重叠。强电箱和弱电箱的水平净距从外壳边缘开始，尺寸线的视觉延长线也止于该边缘；2D 箱体符号沿墙的长度使用 `sizeMm[0]`、进深使用 `sizeMm[2]` 转为模型米数绘制，保持真实尺寸，不受“点位标注比例”影响。该比例默认 50%，可调整点位符号和文字，但调整只对图块的标注显示尺寸生效。内机、梁和风口等施工净空对象也从真实实体外廓量取，但共用场景尺寸线外观。

HVAC 也是统一项目中 HVACSystem-owned 施工数据：室内空调风机、矩形送/回风管、风口、Ctrl 创建的墙体矩形穿孔、86 控温器以及 HVAC 专用控制线管均归 HVACSystem，不属于 Pascal 建筑节点。空调是与点位、梁同级的编辑工具，空调区也必须保留同一放置模式的“放内机”和“画风管”明确入口；空调区只在空调模式或选中空调对象时显示。悬停放置会显示完整但不可拾取的内机预览，因此底下的合法 Ceiling、梁面或布局参考面仍能接收落点点击；放置点定义为内机底面，放内机模式同时提供共享 Layout reference plane 的显示开关和高度输入。辅助面不参与风管绘制：点击“画风管”后，直接点击蓝色送风口或橙色回风口会自动开始对应路线。首段矩形风管按所点端口的外向截面方向离开并随内机 yaw 旋转；确认首段后才按鼠标选择正交方向。单击始终只确认一个拐点，双击或 Enter 才提交已经确认的整条风管。每次进入普通画管、分支、HVAC 风管或 HVAC 控制线管模式，以及开始一条新路线时，正交默认开启并清除旧世界轴锁；`Shift` 可在当前绘制会话中切换正交，`← / ↑ / →` 锁定世界 X / Y / Z，`↓` 取消世界轴并回到自由模式。已有世界轴锁定时按 `Shift` 会取消轴锁并开启正交；世界轴仍可悬空绘制。活动路线中每按一次 `Esc` 撤回最近一步：普通画管和分支逐点撤回并保留分支锚点，穿透预览先取消，已确认穿透在撤回相关点时同步移除其记录；HVAC 控制管逐个撤回途经点，HVAC 风管逐段撤回末端风管。活动路线时即使焦点仍在侧栏输入框，`Esc` 也优先执行撤回。白色 HVAC 控制线管沿用这些快捷键：正交方向按当前端点的宿主面基轴计算，世界轴锁定则沿 X/Y/Z 预览；不与目标端口对齐时先确认辅助对齐点，再继续连接。空调工具区的控件同步显示正交状态和世界轴锁定，便于鼠标与键盘切换。加风口时，鼠标命中的风管外表面决定开口面和沿段位置，并显示强对比白色默认尺寸预览；单击才创建。该物理面在创建后固定，选中已创建风口时，以开口两端到所在管面边缘的两条橙色尺寸线和起点/终点净距字段调整沿段位置，领域校验继续拒绝越出所在面的尺寸或位置。选中未接管内机时，属性区提供底部标高及 `+X`、`−X`、`+Z`、`−Z` 四个水平净距：每条 3D 尺寸线从内机真实外廓的世界轴向边界起算，并止于该方向首个墙实体面或垂直范围相交的另一台内机实体面；绝不从对象中心点起算。接管后定位和旋转锁定。当前只支持每台内机各一条不分支的送风和回风路线、直段和固定 90° 弯头；不自动路由、拉伸、变径或生成施工合规结论。

已连接任一风管的内机位置和水平旋转锁定，避免暗中移动端口或重布路径；共享风管截面仍可编辑并同步到两条路线。墙体穿孔的净空固定为共享截面宽高各加 50 mm，作为统一项目 `HVACSystem.wallPenetrations` 的施工证据保存，而非只读建筑修改或结构审批。控温器仅可放到墙或梁侧面；86 盒体跟随宿主面定向。未接线时，通用 `L` 起点选择和 HVAC 控制绘制模式显示普通 86 底盒同款四边、每边双孔的 8 个可选孔；点击后把选中孔的安装面坐标及方向写入唯一稳定控制端口，再从该孔起画。每个温控器仍只允许一条控制管。导入旧版 Demo 自动生成的正面外移 25 mm 控制端口时，仅当端口仍符合旧模板且关联路线首段仍从原端口起始，才把端口和该首段起点移到下沿首孔；保持端口、路线、管段 ID 及连接关系不变，保留首段终点和所有后续几何。其他端口或无法确认的几何不迁移；再次导出会保存归一后的端口与首段起点。HVACControlConduit 从所选孔沿面起接，与普通墙面 86 底盒孔位和半埋管心一致。控制路线保持独立 HVAC 系统身份，在 2D、3D 中按真实管段和大弯几何显示。3D 空调对象不显示名称、设备说明或电源/控制端文字框；送风口与回风口文字只在对应内机被选中时显示。FCU 的红色电源和白色控制接口均显示沿端口方向伸出的实体承口；实体可点击，方向跟随端口，斜视时也能看到接口外壳与彩色端面。对应路线模式仅把当前开放且兼容的接口显示为绿色；其他模式显示红色电源色或紫色控制色。通用 `L` 起点选择会高亮可起画的控温器控制源端与 FCU 送/回风口，FCU 控制端只在已有控制路线草稿时作为绿色目标。点击非活动端口仍可选中设备；控温器名称仍在属性面板中显示和编辑。电源线从强电箱红色端口起画并有草稿后，开放的 FCU 电源目标才显示为绿色；未进入对应绘制模式时，HVAC 电源和控制端不会提示为可连接点。FCU 电源端接入 ElectricalSystem receptacle 路线；控制端目标点击沿用目标端口吸附与辅助对齐提示，方向未对准时先确认对齐点并继续绘制。旧 HVACSystem.controls 导入时删除，需人工补画管线。选中墙面控温器后，3D 与普通墙面点位一样显示安装面内上、下、左、右四向中心定位尺寸；未接控制线时，输入框回车或失焦可按任一方向调整位置；已接控制线的温控器位置锁定，先删除路线再移动。2D 空调图按同一内机外廓、端口宽度、风管截面宽度、风口位置和控温器 86 mm 外廓投影，端口以内嵌“送”/“回”色块区分；控温器显示墙面标高与定位尺寸，内机尺寸从外壳实体边缘量到该方向第一次命中的墙体实体面，直风管显示端点长度，截面以可移动说明框表达。

当 2D 与 3D 同时打开同一项目时，3D 在提交设备编辑前会同步共享 Overlay；因此 2D 已保存的点位说明框、定位尺寸数字和尺寸线位置会随 3D 高度编辑保留。自动说明框和点位定位尺寸首次显示时会保存分组、横竖排、行顺序、文字框位置、尺寸数字位置与尺寸线偏移；高度编辑只更新其 `H=` 值，不触发重新分组或重建既有定位尺寸链的绘图位置。2D 与 3D 共享纯几何测量核心：墙面点位尺寸边界与电箱外壳边缘由同一物理三角面射线命中器给出，楼板完成面和 100 mm 默认墙厚由共享解析提供；两视图只各自处理尺寸链/标签布局与绘制。2D 保留其尺寸线投影坐标，measurement basis、assumptions、confidence 和 source object IDs 指向原始实体 witness。墙上定位尺寸链在端部优先命中相接墙的房间侧实体面；没有相接墙时使用本墙实体端面，显示值始终由绘制的实体见证点直接计算。新增点位只保存其相关的新布局记录，不覆盖现有记录。删除点位、改变平面宿主/类型/系统或改变已保存组的成员时，才会使受影响派生标注不再适用。

有效 Demo Beam 的底面、侧面和端面可作为施工管线宿主；顶面与 Ceiling 相接，不可选择。梁面路由保持明装且不产生槽。从墙面已确认管端继续绘制时，明确命中的梁面优先成为预览和确认落点；正交锁定时，落点是受约束方向与该梁面的真实交点，而不是原始鼠标命中点。若该方向无法抵达梁面，单击会确认当前墙/天花上的辅助对齐点，用户可继续逐点转向梁面，不会生成自由的斜向连接或卡住绘制会话。Ceiling 与梁之间沿用同一规则。梁面上的电气转角显示直角弯配件，其余电气大弯使用画管时设置的半径，默认 150 mm；调参仅影响新画管道，既有弯头保持原半径。渲染器之外的解析碰撞检查仍会把有效梁实体作为障碍物，因此悬空和世界轴向管段进入梁体也会显示红色冲突并阻止提交；无效导入梁不会成为宿主或障碍物。

所有当前设备类型也可选择有效 Beam 的底面、侧面和端面；显示几何和端口按该面法线与基准定向，顶面不会成为点位候选。2D+3D 分屏中在 2D 选择 Overlay 点位，会同步成为 3D 面板的活动点位，可直接输入定位尺寸；这不赋予 2D 编辑能力。允许 Ceiling 安装的点位在实际 Ceiling、梁或楼板上被选中后，提供安装面四向尺寸和相对完成地的标高输入；首次修改 Ceiling 或 Beam 点位会保留其世界坐标并改为独立 Installation reference plane 关系。楼板顶面点位在编辑水平净距时继续附着真实楼板，不转成参考平面；地插因此保留 2D 地插符号，且不显示参考平面专属的完成地标高和下方首个实体净距字段。参考平面点位另外向下量到首个实体表面，并保留单独的完成地标高输入与多选统一改标高。墙面点位只把同墙且中心高度相同的另一点位作为水平尺寸目标，距离量到对方中心；梁、天花、楼板等非墙宿主也可使用同宿主、同一面的其他点位作为中心目标，横向偏差容许 100 mm，显示值为实际中心距，射线/连线更早命中真实建筑表面时由该实体作为见证。管线、参考平面和不同宿主的点位不参与。墙端、洞口、楼板、墙顶以及与尺寸射线相交的梁、天花、门窗可成为实体见证点；家具及其 Viewer 占位外廓始终不参与尺寸测量，家具图层开关不改变读数；墙面向上尺寸固定量到宿主墙顶，向下量到楼板顶面。 墙面插座、开关、网络插座的向下尺寸从 86 盒下边缘量到楼板顶面，输入值按该净距调整高度；左、右和向上尺寸仍从点位中心量取。地插向下离地值固定显示为 0 mm。参考面不参与。当前 Viewer 不显示 Column 柱体，因此柱体暂不参与尺寸。图层显隐不改变真实几何见证点。无目标的方向不显示数值或尺寸线；非墙宿主的显示线段沿宿主法线抬高 25 mm，标签在屏幕空间按稳定次序分开。FCU 内机和风口继续按各自外廓量净距。编辑梁不会拖动设备或管线：仍接触该面的关系保留，失效关系会在同一工作区事务中清除为未宿主。仍承载设备的梁会拒绝删除并显示设备身份；未承载时仅清理该梁穿孔，不改写剩余管线坐标。这些可视化记录不构成荷载、配筋、开孔安全区、规范或结构审批结论。

3D 建筑展示不写入 Drawing。2D 自动尺寸与施工标注的布局及来源证据保存在楼层默认施工图；同楼层其他 Drawing 原样保留。2D 手工测量仍只属于当前会话。

## 数据诚实性与降级

- 仅传递源 JSON 已有的节点和变换；根节点缺失时仅从 `parentId` 为空的节点推导，并显示诊断。
- `slab.elevation` 在 Pascal 中表示从本层 Y=0 向上的楼板厚度；3D 按该厚度挤出楼板，并把位于其 polygon 内、普通落地家具的源 Y 坐标放在楼板顶面之上。墙面/天花附着对象不套用该抬升。
- `roof` / `roof-segment` 缺失时显示“当前文件无屋顶数据”，不得补造屋顶。
- 未承诺的第三方节点保留在输入中并显示信息诊断。
- 不加载 GLB；家具统一以由源 `asset.dimensions × item.scale` 得出的尺寸占位展示，避免在一个场景中并发请求大量模型。

## 展示控制

Builder 风格底部主栏提供「系统」入口，第二行列出十个系统。选系统只切换左侧常驻栏的工具卡片，不改变当前视图；未选择系统时系统栏为空，未实现的系统在选中后明确显示空状态。电气、照明、空调、智能、消防的卡片按“放置设备 / 绘制 / 编辑动作”分区并锁定目录。弱电箱和网络面板归电气；温湿度传感器归空调；RFID 读写器归智能；强电箱从电气创建，照明管复用其端口。空调卡片支持从温控器端口绘制控制管，不提供温控器逻辑关联动作。给排水、净水、卫浴、灌溉、燃气仍显示系统入口和明确空状态。点击已有设备、管线、风管或梁的创作卡片时，纯 2D 进入 3D，分屏保留分屏。3D 路线参数和创作辅助工具位于可调宽、可隐藏的常驻左栏；选中对象后，其属性显示在画布右侧的窄悬浮框，按所属系统命名，取消选择即关闭。当前未接入的 Builder 主栏动作禁用，不会写入项目数据。

画布左上角提供 3D、2D、分屏与单一楼层选择。分屏中的建筑 3D 视图与 2D 图纸同步显示所选楼层；系统创作卡片只在开始创作时将纯 2D 切至 3D。3D 画布右上角的「图层」弹层只控制 3D：建筑组提供墙体、梁、楼板、天花、屋顶、门窗、家具与楼梯、空间名称；系统组按十个 Project 容器列出电气、给排水、照明、空调、智能、净水、卫浴、消防、灌溉和燃气，当前无 Demo 作者实体的系统仍保留开关。强电箱、弱电箱、插座与网络端点归电气；开关、灯位接线盒及照明管线归照明；温湿度传感器与 HVAC 对象归空调；RFID 读写器归智能。共享强电箱始终按 ElectricalSystem 所有权显隐，即使其端口供照明管线使用。未知合法未来节点仍往返保留，当前不承诺渲染；今后可渲染的系统节点应按其 Site 容器所有权受对应开关控制。建筑和系统图层显隐只保存在当前 3D 会话，不写入 Project JSON，也不改变 2D 左侧「图纸」标签中的独立图层状态；左侧创作工具不重复提供 3D 图层菜单。旧 3D 顶部的外观/室内、视角、投影、叠放/爆炸和墙体详细控件已移除。底部主栏保留顶视图快捷入口，每次点击都会重新定位到正上方视角，即使相机已经处于顶视图。相机可鼠标旋转、右键平移和滚轮缩放；场景几何不注册为相机碰撞体，世界地面仍保留最低高度边界但不增加拖动摩擦，因此镜头移动不会被家具、管线或地面边界渐慢拖住。

创建或编辑 Beam 会更新建筑项目数据，但不会重置用户已调整的相机位置或角度；只有用户选择镜头预设或重建画布时才应用预设视角。


Project JSON 版本边界为 4.0：3.0 及更早格式和退休公共类型会被拒绝导入，不提供自动迁移；旧 4.0 `Spotlight` 按兼容别名导入并导出为 `LightingJunctionBox`。公开目录使用 `NetworkOutlet`、`LightingJunctionBox`、`FanCoilUnit`、`FCUThermostat`、`TemperatureHumiditySensor`、`RFIDReader`、`GalvanizedSheetMetalDuct` 等具体类型；内部 Overlay 通用名仅是适配实现细节。消防管以 `FireWaterPipe` 自由起画，不需要入户点，不创建 Circuit；弯头、三通、直接接头分别使用 `FireWaterPipeElbow`、`FireWaterPipeTee`、`FireWaterPipeConnector`。FCU 默认外壳为 1000 × 600 × 300 mm，镀锌铁皮风管截面为 500 × 200 mm。

3D 选择模式中，单击管段或管件只选择该元素；双击沿 fittings 的连接关系选择连续管路；三击按所属 Circuit 扩展到全部管段及其相关 fittings 和 86 接线盒。无 Circuit 的消防管等退回到 fittings 所连接的物理连通范围。`Delete`/`Backspace` 对当前高亮的管线元素集合执行一次删除，并清理相应设备端口引用、空 Circuit、槽、穿孔及施工标注；Circuit 仍有剩余管段时保留其余拓扑并标为 broken。2D 图纸保持只读，不提供管线集合删除。
