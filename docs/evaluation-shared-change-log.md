- Tab 穿透保存入口宿主、入口、出口与冻结的入射方向；旧单点穿孔仍可读取，并明确标记为派生兼容数据。普通宿主面绘制不会因穿透产生无宿主坐标，世界 XYZ 仍是唯一的悬空绘制入口。
- 旧 `wall-chase` 自动迁移为通用 `surface-chase`；电气贴面暗敷的墙体和楼板直线/圆弧槽只切割运行时建筑克隆，天花与消防不切槽。切割失败保留 Overlay 并使用替代槽线，不影响二维几何或评价数据。
- 3D 相机仅以世界地面作为轻微边界，墙、天花、家具、管线和隐藏节点均不注册为碰撞体；该展示交互不改变场景几何、Parser 或评价数据。

# 2026-09-05 · 管线点位放置与施工面板精简

- 管段内插入设备不再套用设备手动放置的默认宿主限制；点位单击、双击与 Enter 复用同一提交路径。电箱输出端口在箱体表面自动错位并按新线路动态增加，避免多回路共用同一几何起点。

# 2026-09-05 · 管线实时预览性能整理

- 高频指针命中合并为每个动画帧至多一次展示更新；点击、双击、Enter 和 Tab 仍读取最新原始命中点，预览与最终落点精度及管线路由语义不变。
- 2D 永久管网与瞬态草稿拆分渲染，3D 改为按需帧循环；建筑节点、楼层、洞口和楼板关系建立会话索引，空槽孔集合保持稳定引用，避免仅移动鼠标时重建建筑浅槽 CSG。
- 管线碰撞空间索引按不可变 Overlay 引用缓存，源设备通过显式对象 ID 忽略；CSG 中间几何及被替换几何会及时释放。上述优化不修改 Pascal JSON、Overlay 文件格式、Parser、共享几何定义或任何评价证据与结论。

# 2026-09-05 · 槽孔延迟生成与点位性能整理

- 管线提交仍立即保存完整浅槽与穿孔语义，但运行时建筑布尔切割改由“生成/更新槽孔”显式触发；按钮只表达是否存在未应用变化，不展示数量。编辑期间保留轻量槽线，因此 Overlay、导出、撤销和施工关系不丢失。
- 点位管段预览按动画帧合并；不可变 Overlay 在本地历史与 2D/3D 同步间保留结构共享，设备诊断和槽线可见性查找改用索引，避免放置轻量设备时复制整网或重算全部 CSG。
- 3D 悬浮编辑面板继续支持滚动，但隐藏原生滚动条。以上均为管线 Demo 的运行时与展示优化，不修改 Pascal JSON、Parser、共享几何定义、Evaluation Handoff 或任何评价结论。
