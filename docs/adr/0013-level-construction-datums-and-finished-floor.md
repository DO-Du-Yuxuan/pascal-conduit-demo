# Level-owned construction datums and explicit finished floors

施工放线需要一个跨设备系统、跨房间且可保存重用的基准。每层的水平施工基准作为 Demo 拥有的可选 `Level.constructionDatums` 元数据保存于同一 Project 4.0 JSON；它不归任一设备系统或某张 Drawing，也不赋予导入建筑几何编辑权限。Drawing 通过稳定来源 ID 保存派生测量依据和自己的绘图布局。这样修改图纸布局或切换系统不会改变施工基准，也避免为同一个基准保存多份独立线几何。

水平基准采用一个明确毛坯参考与全层共用的确定标高，不逐墙追随毛坯地面的高差。完成面需单独明确确认，区域完成面保存为相对本层通用完成面的差值；首版区域只引用明确的同层 Zone，不将覆盖整层的 Slab 猜作房间。墙面显示线及由定位见证产生的垂直基准线均由源数据计算，门窗洞口不绘制跨洞连接。修改基准或完成面保留已放设备及管线的位置，以免把施工依据修正变成隐式改线；移动设备仍通过明确的定位动作执行。

已有无基准的 4.0 文件继续有效，不迁移或自动补成已确认完成面。新增元数据保留未知字段和稳定身份；缺少完成面时继续标明缺口和既有模型测量依据。具体数值、显示与证据合同见[施工基准](../construction-datum.md)。
