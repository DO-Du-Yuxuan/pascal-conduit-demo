# Derive finished-floor placement surfaces without altering imported slabs

完成面定位面从 Level 已确认的施工基准完成面标高、同层 Slab 范围与明确 Zone 差值派生。它不另存一份地面几何，也不修改导入 Slab 或创建代表砂浆、地砖的建筑实体；孔洞和区域边界保留。这样完成面定位可先用于地面点位，后续真实地面构造作者工具仍有独立的数据归属。

地面设备以新的 `finished-floor` 挂载记录完成面依据，引用稳定的 Level、施工基准、源 Slab 和可选 Zone ID；世界坐标仍是盒体中心，上口是当前安装定位依据。`topOffsetMm` 记录最近明确放置或对齐时的偏差，当前实测偏差始终由世界坐标与当前完成面计算。设备没有伪造的物理 Slab 附件。修改基准、完成面或区域差值不移动设备及既有线路；重新对齐是明确的设备定位动作，并遵守连接锁。

地面平面定位使用同一测量见证生成编号基线、场景尺寸与属性文本，保留四个方向。墙面点位继续按水平高度基线定位，地面点位不要求施工人员再量到 H01 的竖直距离。详细行为见[施工基准](../construction-datum.md)。
