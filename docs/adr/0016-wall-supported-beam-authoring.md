# 墙面支承梁与既有天花标高梁兼容

画梁改为从真实墙面开始，顶部齐平起点墙顶，另一端必须连接同层且同顶标高的墙、柱或已有梁面；移除梁模式的辅助面。Ceiling 底面在已有参数规则下可比墙顶低 10 mm，以 Ceiling 或虚拟面为起点会造成任意悬空起画和错误顶标高。

新梁以 `topElevation` 和 `supports` 保存墙顶来源、明确/推导依据及两端支承身份，不复用名为 `effectiveCeilingElevation` 的旧字段来伪装墙顶依据。既有 Ceiling 梁按旧记录继续校验、渲染和往返保存，避免改变历史施工对象和附着坐标；所有几何消费者统一读取相应的已保存梁顶。此决定替代 ADR 0003 中新梁必须依赖 Ceiling/布局辅助面的部分；点位与空调的辅助面继续保留。
