# Pascal 施工管线路由 Demo

## Demo 文档合同

`README.md` 是同事与 AI 共同读取的当前能力入口：它记录已经实现的用户行为、数据归属、持久化方式和明确边界，并链接到对应的详细合同。专题文档描述当前行为和实现边界，ADR 记录难以反转的取舍及原因；代码和测试负责验证这些陈述。任何用户可见功能、数据归属、保存格式或边界发生变化时，必须在同一次变更中同步更新 README 和适用的专题文档，不能只改代码。

右上角始终显示当前页面的构建版本、Git 短提交号和构建时间，便于确认是否已加载最新部署；发生未捕获的界面渲染错误时，错误页保留版本信息、原始错误与调用栈、React 组件栈、项目 ID、源文件 SHA 和脏状态。错误页可分别下载当前共享工作区提交快照编码成的统一 Project JSON（schema 4.0）与不含项目正文的诊断报告，并可刷新重试。store 文档提交变化时会预先缓存最近一次成功编码的恢复 JSON；若崩溃页即时编码失败，可下载带有时间标记的最近成功快照。没有可恢复项目时按钮禁用。生产构建发布 source map，便于用诊断报告的提交号和 bundle 行列定位源码。恢复文件包含崩溃时 store 中最后提交的状态，不包含尚未提交的临时鼠标预览；此功能处理 React 子树渲染错误，不覆盖浏览器/标签页崩溃或所有异步、事件处理错误。详见[工作区持久化合同](docs/editable-project-workspace.md)。

## 保留的 Viewer 能力

工作区采用本地 Builder 的暖色界面、字体、图标和控件层级。左栏新增只读场景树，可按名称、类型或 ID 搜索和选择建筑对象；系统与图纸分别保留自己的工具。工作区底部提供居中于画布的 Builder 主栏，按「选择、框选、场地、建造、布置、系统、区域、删除、吸附、参考图、旋转、顶视图」排列。当前 Demo 可从「建造」进入梁工具、从「系统」第二行选择电气、给排水、照明、空调、智能、净水、卫浴、消防、灌溉、燃气；未接入的 Builder 动作明确禁用。选系统不会切换视图；左侧可调宽、可隐藏的常驻栏在选中系统后展示设备卡片，未选择系统时显示入口提示；场景标签显示只读建筑树。电气、照明、空调、智能、消防卡片调用真实 3D 作者工具；每个系统卡片按“放置设备 / 绘制 / 编辑动作”分区，并锁定目录及其允许的操作。系统目录始终可见：电气、照明、空调、智能、消防可创作；给排水、净水、卫浴、灌溉、燃气保留入口并显示空状态。弱电箱和网络面板归电气，温湿度传感器归空调，RFID 读写器归智能。FCU 控制管从温控器端口起画并接至 FCU 控制端口。纯 2D 点击创作卡片切至 3D，分屏保持分屏。其余系统显示暂无编辑工具的空状态，导入数据仍保留。3D 创作参数保留在左侧常驻栏；选中对象的属性在画布右侧窄悬浮框中显示，并按所属系统命名。详见 [3D Viewer 边界](docs/3d-readonly-viewer.md)。

- 原始 Pascal JSON 宽容解析、解析诊断、二维单画布、统一楼层切换、旋转、平移、缩放、测量、图层和对象隐藏/恢复。
- 主栏「框选」可在 3D 当前楼层左键拖出水平矩形，按 dsphere 的相交范围选择对象；Ctrl/⌘ 拖动追加选择，短点击仍可普通选择。纯 2D 点击框选进入 3D，分屏保持分屏；框选只改变会话选择，导入建筑仍只读。详见 [3D Viewer 边界](docs/3d-readonly-viewer.md)。
- 支持纯 2D、纯 3D 与可拖动的 2D+3D 分屏；画布左上角的统一楼层选择器让分屏两侧显示同一楼层，切换视图不会重新解析底图或清空 Overlay。2D 工作区只显示一张画布，原有 Drawing 数据仍保留。
- 3D 画布以单层建筑视图显示，底部主栏提供顶视图快捷操作。左下角约 80 × 80 px 的 XYZ 方向指示器距画布左侧与底部保持相同间距，并随画布尺寸调整位置、随相机实时旋转，红 X、绿 Y、蓝 Z 对应绘制坐标轴；建筑旋转后仍与管线轴锁一致。纯 3D、分屏、透视和正交视图均显示，指示器只显示方向，点击不切换视角。
- 底部「建造」第二行提供「施工基准」数值工具。每层可设置唯一 H01 基线；作者栏只需填写“基线离毛坯地面”和“水平基线离完成面高度”两个毫米数值；第二项留空表示完成面尚未定义，完成面由基线标高减去该高度生成。系统会自动采用唯一楼板顶，或顶标高相同的楼板顶；顶标高不一致时可用“选参考地面”后点击本层楼板。已有基线编辑保留其原始参考。墙面标线在门窗洞口中断，文字以约 48 mm 固定物理字高贴在墙面外侧，随墙体方向旋转并受实体遮挡。Zone 属性可设相对本层完成面的正负高低差。全局基线编辑更新线和设备相对基线尺寸，不移动设备；设备和完成面不变时，设备相对完成面的高度保持不变。选中设备可编辑底边高于/低于基线的毫米数，连接中的设备遵守既有定位锁。图纸高度与安装表保留基准、原始参考楼板和局部 Zone 的证据 ID。详见[施工基准合同](docs/construction-datum.md)和[ADR 0013](docs/adr/0013-level-construction-datums-and-finished-floor.md)。
- 3D 相机保留世界地面的最低高度限制，但边界不增加拖动摩擦；墙、天花、家具、管线和隐藏节点均不作为相机碰撞体，可直接穿过。顶视图按钮每次点击都会重新定位相机。
- 3D 画布右上角的「图层」按钮分别控制建筑和十个系统容器的内容；系统组包含电气、给排水、照明、空调、智能、净水、卫浴、消防、灌溉、燃气，当前无作者实体的系统仍保留开关。强电箱、弱电箱、插座与网络端点归电气，开关和灯位接线盒归照明，温湿度传感器与 HVAC 对象归空调，RFID 归智能。3D 图层显隐只作用于当前 3D 会话，不写入 Project JSON，也不影响 2D「图纸」标签中的独立图层开关；左侧创作工具不重复提供 3D 图层菜单。
- 选中点位时，3D 保留模型测量值与实体见证；选中点位的定位数字统一以约 34 mm 固定物理字高绘制在安装面，使用浅色近不透明小底框和细边；墙面文字沿墙方向排字、两侧均不镜像并受墙体遮挡，非墙文字按宿主 basis 贴面排布，不使用 Html 或屏幕 billboard。尺寸线仍连接实际测量 witness，显示投影不改变尺寸值。相接墙角的红色基准线沿两墙真实可见面的交界棱绘制，设备高度处与橙色尺寸线共用显示锚点；线宽约 3.75 px、无红色端球并保留实体深度测试。施工基准 H01 标签保持约 48 mm 无底框物理文字。墙面主定位只显示 H01 底边偏差与左右实际基准；短标记写“下缘高于 H01 217 mm”“左基准 1197 mm”等，点位到参考线的数值只标一次，若目标是另一点位则保留其名称。属性主区用“下边缘相对水平基线 H01”及左右垂直基准线定位；已确认完成面时只读显示下边缘至完成地面的派生高度，原始楼板顶/模型地面距离和墙顶净距收在折叠的“实体净距”内。未配置 H01 时仍可编辑明确命名的楼板顶面或模型楼层基准距离。梁面、天花、楼板和参考平面的非墙点位继续使用既有四向或向下定位尺寸与标签布局；地插仍按实际楼板宿主计量。详见[3D Viewer 合同](docs/3d-readonly-viewer.md)和[施工基准合同](docs/construction-datum.md)。
- 3D 选择模式可用 Ctrl/⌘ 多选设备；选中相同类型点位时，修改宽、高、深会将该项尺寸应用到所有选中点位，未编辑的尺寸轴各自保留。混合类型选择不提供批量尺寸编辑。普通设备只要任一端口接管，尺寸编辑锁定，避免移动已连接端口；灯位接线盒任一端口接管后只锁定直径，深度仍可批量修改。参考面点位的统一改标高仍按其既有批量规则执行。
- 场景树眼睛支持逐个隐藏/恢复，并同步反映 3D 建筑图层；显示状态只在会话内生效，不修改源节点。
- Studio 建筑配色、灯光、可关闭阴影与屏幕深度/法线轮廓；同层墙体拼接、门窗洞口、楼板厚度、天花、真实楼梯踏步/栏杆、坡面屋顶与源天窗、柱与栏杆，以及家具尺寸占位。柱与栏杆只读展示，不新增施工宿主或测量目标。无 roof 数据时明确提示，绝不虚构屋顶。

## 管线 Demo

消防信号白线与红、蓝、白网络线管共用自动过桥、大弯、梁换面 90° 弯头、定尺、辅助对齐及轴锁的几何规则。悬空和世界轴点列无需宿主也可按真实交叉生成过桥；既有消防信号直管、大弯和桥体均可作为避让障碍。消防信号过桥保存在 `FireProtectionSystem` 的 `FireSignalConduitElbow.bridge` 中，导入后继续按过桥几何显示。消防水管保持不自动过桥；消防信号仍不使用 Circuit，也不与其他系统端口互接。

喷淋头方向箭头在 2D 图块中从中心到箭头尖端为 20 个符号单位（原为 10），圆环大小保持不变；图例保留真实向上喷/向下喷方向并完整显示箭头。管段挂载设备的图例及安装高度表与符号、定位尺寸共用挂载判断，列为“管段”，不因管段继承的建筑附件被误排除；数量及来源 ID 包含当前楼层所有可见同类点位。

管段安装设备（`mount.kind: "segment"`）的 2D 符号使用保存的真实世界 X/Z 坐标，不按管段继承的墙面局部坐标重新定位。主管插入喷淋头时，喷淋头及其端口只保存支管末端位置与管段挂载、楼层引用，不继承主管的建筑宿主附件；新插入喷淋头默认向上喷。

FCU 控制端口的绿色承口扩大鼠标命中区域，并在左键按下时确认。HVAC 控制管的实时预览、端口悬停校验和最终提交共用普通管线 `planRoute` 的点列、管径、定尺和大弯半径；预览直接绘制计划直管段和扫弯管件，自交或实体碰撞时以红色显示。已保存的控制管也复用普通管线的管段与弯头几何，避免预览、碰撞判断和实体外观出现不同的弯折。悬停显示“连接后结束”前，会用与实际提交相同的整条控制管规划检查大弯空间与实体碰撞；不能提交时直接显示具体原因，可按 `Esc` 撤回最近的途经点再调整路径。

- 插座线路：红色 `#ef4444`，20 mm；照明线路：蓝色 `#3b82f6`，20 mm；网络线路：白色（灰描边），20 mm；消防水管：绿色 `#22c55e`，50 mm。
- “点位”工具可手动放置强电箱、弱电箱、插座、开关、灯位接线盒、网络面板和默认朝上的喷淋头；全部使用轻量参数化几何。
- 新线路必须从合法端口开始：红色插座和蓝色照明来自强电箱，白色网络来自弱电箱，消防水管可从用户确认的首点自由起画，也可从兼容开放管端续画，不需要入户点且不创建 Circuit。按 `L` 进入通用画管起点选择，显示所有可起画系统的绿色设备端口、86 底盒孔位、开放管端、HVAC 送/回风端口和控温器控制端；点击来源后路线自动切换到对应系统，左侧固定工具栏也切换到该系统。强电箱共享插座与照明的物理孔，按左侧当前系统显示红色或蓝色可用孔。独立 Builder 画管卡仍锁定到卡片所属系统，绿色提示只显示该卡可用的来源。已接源插座、开关和灯位接线盒可继续出线；左键可从兼容开放管端续画，绘制另一条同系统管线时也可确认辅助对齐点，但不会自动把两条管道连接。网络面板只能接到白线开放端，且自身与喷淋头都是终点。
- 消防水管从自由起点或开放主管端起画后，先确认主管点，再点击开放的喷淋头端口会生成消防三通和支管；未对准时左键先确认辅助点，管线到达真实端口后再次点击喷淋头提交。喷淋头只作为支路终点，三通另留 150 mm 主管短管和开放端，用户可从该端继续绘制并重复连接下一只喷淋头。支管最短有效长度为 120 mm，目标与主管方向过近或长度不足时会提示重新确认主管点。主管、三通、支管和喷淋头端口均保存物理连接引用，不创建 Circuit。已连一根消防管的喷淋头可从同一端口继续起画一根出管，使喷淋头成为管网中的真实连接点；端口最多接两根消防管（入管和出管），未接管喷淋头不能无源起画。新管引用同一稳定端口，删除任一相连管会准确释放对应引用，既有管段几何不变。
- 消防信号管为独立的 20 mm 白色线管，归属消防系统，可从烟感端口连接至另一烟感或在墙面封闭终止，不创建 Circuit。2D 使用单一“消防施工图”开关共同显示消防水管、喷淋头、烟感和消防信号管；底层数据仍分别归属喷淋与消防信号系统，3D 图层行为不变。信号管以较深灰色轮廓和白芯绘制，烟感使用同色深灰轮廓与白芯；悬空信号管按其他非消防水管规则显示虚线。
- 3D 消防工具卡提供“烟感”和“绘制消防信号线”。烟感放置在 Ceiling 或 Beam，圆形外形默认直径 60 mm、深度 30 mm，带四个独立消防信号端口；未接线时可编辑直径和深度，接线后锁定直径但仍可编辑深度。绘制信号线从烟感绿色空闲端口起画，左键可确认空间途经点；点击另一只烟感的开放端口时沿用辅助对齐：先点击确认对齐点，再点击端口连接。双击或 Enter 可在任意已确认点完成；空间末端保持开放，可从该端续接。墙面可吸附并确认终点，完成后保存为封闭墙端，不占烟感端口且不能续接。烟感与信号管共用 3D 消防图层开关。
- 3D 是唯一绘制入口。每次进入普通画管、分支、空调风管或 HVAC 控制线管模式，以及开始一条新路线时，正交默认开启并清除上一条路线的世界轴锁；`Shift` 可切换正交，`← / ↑ / →` 锁定世界 X/Y/Z 轴，`↓` 取消世界轴并回到自由模式。已有世界轴锁定时按 `Shift` 会取消轴锁并开启正交。左键选择/落点，右键旋转，中键或空格加左键按屏幕方向平移，滚轮缩放；导航手势不落施工点且不清草稿，`V` 切换选择；普通线路双击或 `Enter` 完成。活动路线中每按一次 `Esc` 撤回最近一个已确认点；分支保留原分支锚点，穿透预览先取消，已确认穿透会随撤回同步移除对应记录。HVAC 控制管逐个撤回途经点，HVAC 风管逐段撤回末端风管；活动路线时即使焦点仍在左侧输入框，`Esc` 也会优先撤回。
- 3D 选择模式下，单击选中一个管段或管件，双击选择由管件连续连接的管路，三击选择从所点元素沿实际管件、86 接线盒端口和设备端口可达的同 Circuit 管段、相关管件与底盒；Circuit 只限定回路范围，不会把被删除管段隔开的部分重新连起来，也不会跨到同一电箱上的其他 Circuit。消防等无 Circuit 的管路按物理连通范围选择，几何上相接但没有连接对象或端口引用的管段不会被视为连通。按 `Delete`/`Backspace` 一次删除全部高亮管线对象，并同步清理关联端口、Circuit、槽孔和标注；选中 HVAC 白色控制管的管段或管件时会删除整条控制管并释放两端端口。2D 图纸可选择但不提供此编辑与删除操作。
- 直管、圆角大弯、消防弯头、三通、直接接头、86 检修盒、过桥弯、墙/楼板浅槽和穿孔保存在统一项目的系统节点中。过桥弯在 4.0 文件中使用 `ConduitElbow` 的 `fitting: "elbow"` 和 `bridge` 几何数据保存，重新导入后恢复相同跨越几何。过桥资格由实际空间交叉决定，不要求楼板宿主、相同宿主 ID 或整段位于唯一楼板内；不会为过桥补写宿主或修改既有管网。世界 X/Z 轴锁定落点仍只在楼板几何校验通过后保留楼板宿主；Y 轴、越界和歧义位置仍不附着。删除部分管段后，仍保留线路连接的 86 底盒可继续显示端口并续画。2D 只读显示同一份端口化管网，可选择但不可编辑。
- 2D 只显示管线连续几何和 86 地盒符号，不为弯头、三通或直接接头额外绘制节点圆点；3D 三通按三个物理端口显示圆筒承口。线管描边宽度取保存直径（毫米换算为米）与相应最小可读宽度中的较大值，因此正常缩放下按实际管径比例绘制，50 mm 消防水管比 20 mm 线管粗；普通线管最小宽度 1.8 屏幕像素，路线预览及 HVAC 控制线最小宽度 2 屏幕像素。网络管保留白色芯线和青色外轮廓；白色消防信号管使用 2.4 屏幕像素的深灰外轮廓与白芯，烟感符号也使用深灰轮廓和白芯，确保白底上可辨；HVAC 控制管使用白芯和灰色细轮廓。2D 的“消防施工图”单一开关共同控制消防水管、喷淋头、烟感和消防信号管；其 Project 所属系统及 3D 图层仍保持独立。无宿主管段可从其精确引用的设备端口所属挂载推定图纸楼层，不从整条 Circuit 推断。除消防水管始终使用实线外，其余系统中位于楼层基准以上 1.8 m 或更高、且不足两端实体宿主的悬浮管段，以及附着在天花背面的管段，均使用虚线，悬空弯头跟随管段线型。墙面端点依据有限墙段和墙体厚度校验，避免陈旧宿主引用把悬空管段显示为实线；贴地开放管端和实际位于墙体、楼板等实体中的管段保持实线。HVAC 控制线管按其温控器与 FCU 的明确挂载归入唯一楼层，使用保存直径和 2 屏幕像素最小宽度，并遵循同一悬空虚线规则；矩形风管保持原有实体投影样式。
- 在 2D+3D 分屏中，3D 的起点、实时中心线、圆角大弯、分支地盒和冲突红色状态会同步预览到 2D；临时预览不写入 Overlay，也不产生撤销记录。
- 实时绘制和管段点位预览按浏览器动画帧合并鼠标更新，2D 永久管网与临时预览分层渲染；碰撞空间索引按不可变 Overlay 复用。以上仅减少重复计算，不降低拾取、碰撞、槽孔或显示精度。
- 分支模式沿已有管段实时预览分支点；红、蓝系统插入同色 `86 × 86 × 50 mm` 检修盒，消防系统插入三通；白色网络线路不允许分支。
- 插座、开关、网络面板以及红/蓝分支产生的 86 底盒均采用四面、每面双孔的端口模板；管线在盒体边缘孔位终止，开始续画时需点击具体孔位。强电箱在下沿和上沿各横向布置 10 个物理孔，插座与照明线路共用这些孔；弱电箱同样在下沿和上沿各布置 10 个网络孔。箱体孔位保留横向与上下排位置，强/弱电箱引出的管心落在安装宿主表面，使墙面出口与普通墙面管线保持同一敷设深度；超出首排的额外端口才沿宿主法线进入后续排。任一系统占用共享孔后其他系统不能重复占用。画管起点尚未确认时，将鼠标悬停到电箱才显示可用孔位，且只有点击具体孔位才会起管，箱体本身不会回退选择首孔。已有管线不会重叠或被移动。插座、开关或分支 86 盒点击已占孔时，盒体会侧移，让同侧另一孔继续承接既有直管并释放被点击孔供新路线使用；旧管不会为追孔而变形。插座、开关和灯位接线盒可通过单击、双击或悬停后按 Enter 插入兼容管段，原管段会在设备端口处截止；悬空管段同样可挂载兼容点位。新建灯位接线盒默认直径 60 mm、深度 30 mm；未接管时修改直径会让四个端口随圆盘边缘移动，接入任一线管后直径锁定但深度仍可修改。导入的既有接线盒尺寸、位置、端口和连接保持原样。灯位接线盒在天花和参考面上保持圆盘朝下，四个接管孔位于圆盘水平面。喷淋头可安装在消防直管上（含转弯后的直管），中部安装会生成三通和短支管，主管不会穿过喷头。
- 四类系统均按 4000 mm 最大中心线定尺自动插入直接接头。红、蓝、白线管只要中心线发生非共线转向，就使用相切大弯，默认半径 150 mm；梁面上的电气角点及梁相邻暴露面之间的换面使用 90° 弯头配件，不占用大弯半径；换面先确认公共棱边，再沿下一面绘制。普通跨宿主、多次换面或 Tab 穿透仍按大弯处理；净空不足时禁止落点和提交。消防继续使用标准弯头。
- 管线实体默认不得交叉，冲突草稿显示红色并禁止左键落点、双击、Enter 或“完成路径”提交。红、蓝、白网络新直管与既有同类系统管线的非平行实体交叉会尝试生成过桥弯，不依赖宿主资格。斜交不再设 11.5° 门槛，桥跨度按实际交叉角和管径计算 10 mm 净空；宿主法线用于选择避让方向，天花及梁底朝外避让，无宿主时使用几何方向。相邻桥的占用区间重叠时合成一桥，分离交叉分别成桥，不设固定 8 桥上限。桥可跨新路线的自动定尺接头规划，保留真实端点及外部端口连接；端部不再固定要求 70 mm 余量，但必须放得下完整桥形。新桥分别记录直管段 ID 与弧形管件 ID。平行重叠、草稿自交、新弯自身的交叉以及无法保持物理净空的路径仍禁止；消防水管不自动过桥；白色 HVAC 控制管复用同一过桥规则。桥体也参加梁碰撞检查；桥不能抬走已明确记录的穿孔通道，未受影响的穿孔仍绑定实际保留管段。共享同一物理端口的接触不算冲突。详见 [过桥几何决策](docs/adr/0010-geometry-based-conduit-bridges.md)。
- Tab 会冻结按键前最后一段的入射方向，沿同一直线穿过入口宿主；出口确认后重新附着实际目标宿主，并恢复 Tab 前的宿主面正交状态。普通自由/正交模式始终依附宿主面，只有世界 X/Y/Z 模式允许悬空走管。
- Viewer 仅保留施工态。槽与穿孔数据随管线路由立即写入 Overlay，但按钮点击前不显示槽、不开槽也不穿孔；左侧“生成/更新槽孔”在存在尚未应用的变化时亮起，点击后才统一对运行时墙体和楼板执行建筑切割。红、蓝、白网络管只有墙面和楼板顶面按暗敷生成浅槽，梁、天花及其他位置均为明敷；消防不生成浅槽；只有切割失败的宿主才显示替代槽线。原始 Pascal JSON 永远不被修改。

墙/楼板浅槽宽度默认是管径 + 10 mm、深度是管径 + 5 mm；穿孔直径是管径 + 10 mm。画管面板可将大弯半径设为 50–1000 mm，默认 150 mm；新画管道的弯头保存采用的半径与弧线，已画弯头不受后来调参影响。定尺长度固定为 4000 mm；槽孔尺寸仍是可编辑的 Demo 参数，不是施工规范结论。消防喷淋默认吊顶内明敷，不生成浅槽。

内部 Overlay 是 Project JSON 4.0 的编辑适配快照，不是独立文件格式或第二数据源。所有 Overlay 对象及其物理端口必须使用唯一 ID：导入会拒绝重复 ID，且新建点位、管段、管件、分支盒、槽和穿孔都会生成新的稳定唯一 ID，绝不改写既有对象身份。本 Demo 不判断照明开关控制关系、配电负荷、回路容量、喷淋覆盖、间距或消防合规。

## 空调送回风 Demo

FCU 空调内机、镀锌铁皮矩形送风/回风管、风口、墙体穿孔、86 空调控温器和物理控制线管都保存在统一项目的 `HVACSystem` 中；编辑器内部仍用 HVAC Overlay 快照处理交互。`GalvanizedSheetMetalDuct.segments` 与 `HVACControlConduit.segments` 内嵌稳定 ID 的管段，控制弯头保存大弯半径和弧线几何；它们不修改只读建筑节点。旧 `HVACSystem.controls` 逻辑关联在导入时删除，不推断或自动生成管线路径。FCU 与温控器分别嵌入稳定的电源和控制端口；红色 FCU 电源管是 ElectricalSystem `Conduit`，白色 HVAC 控制管属于 HVACSystem，不能与白色网络管互接。控制管默认直径 20 mm，从温控器起画到 FCU，不需要先连接弱电箱。白色 HVAC 控制管与红、蓝、白网络管复用过桥、梁换面 90° 弯头、定尺、辅助对齐和轴锁逻辑；墙面与楼板顶面暗敷，其余明敷。控制管槽保存在 HVACSystem，施工生成与显示跟随 HVAC 图层。FCU 内机默认 `1000 × 600 × 300 mm`，并与一条送风路线和一条回风路线共用 `500 × 200 mm` 的镀锌铁皮矩形风管截面。内机是与“点位”“梁”同级的主工具；空调区也保留同一模式的“放内机”和“画风管”明确入口。点击“画风管”后，蓝色送风口与橙色回风口是两条路线唯一的起点；直接点击端口即可开始对应风管。首段必定沿所点端口的外向截面方向离开（随内机旋转），之后才按鼠标选择正交方向；每次单击只确认一个风管点，双击或 `Enter` 才完成整条路线。新风管和控制线默认正交并清除旧 XYZ 轴锁，`Shift` 可切换正交，← / ↑ / → 分别锁定 X / Y / Z，↓ 取消世界轴。白色 HVAC 控制线管正交状态只约束当前鼠标段，点击后下一段重新选向。两条风管只支持直段和固定 90° 弯头，不支持三通、异形弯头、变径或自动布管；每个内机端口在当前版本最多接一条连续路线。

内机可放在 Ceiling、梁面或既有 Layout reference plane，并只允许水平旋转；放置点承载内机底面，预览本身不拦截落点点击。辅助面只服务放内机模式，保留显示开关和高度输入，关闭参考面不会改变已有对象；风管使用实体端口、宿主面与世界轴约束，不依赖辅助面。空调工具区只在空调模式或选择空调对象时显示，不能遮住点位、画管、分支等其他工具。选中未接管内机后，属性区以灯位接线盒同款的底部标高及 `+X`、`−X`、`+Z`、`−Z` 净距字段编辑位置，并在 3D 用同款橙色尺寸线显示这些数值。四条水平尺寸线均从内机真实外廓起算，沿世界轴延长到首个墙实体面或同标高相交的另一台内机实体面，而不使用任一对象中心点；内机连接任一风管、电源线或控制线后，位置、外壳长度和旋转锁定，仍可修改共享截面并同步呈现到所有已连风管。作者可选中风管末端段输入长度；若缩短后会使已有风口越界，操作被拒绝。加风口时不预选“面”：鼠标悬停风管外表面就实时显示白色默认矩形风口，单击确认；命中的物理面随后固定，选中后以起点和终点两条橙色尺寸线及对应净距字段调整沿段位置。风口从承载风管自动继承送/回风身份，可在同一面存在多个，但矩形必须完整落在该风管面内。绘制风管时按住 Ctrl 命中墙面会保留固定净空（截面宽高各加 50 mm）的矩形墙体穿孔证据；这是 Demo 施工表达，不构成结构或规范结论。

控温器是仅墙面/梁侧面可放置的 86 面板，盒体跟随宿主面定向。未接线时，画管起点选择与 HVAC 控制绘制模式显示普通 86 底盒同款四边、每边双孔的 8 个可选孔；点击后把选中孔的安装面坐标和出线方向写入唯一稳定控制端口，再从该孔起画。一个温控器仍只接一根控制管，遵循 ADR 0008 的一对一拓扑。导入旧版 Demo 自动生成的正面外移 25 mm 控制端口时，仅在端口仍符合旧模板且关联路线首段仍从该端口起始的情况下，将端口和首段起点归一到下沿首孔；端口、管段和路线 ID、连接关系及首段终点之后的几何均保留，未知或人工修改过的端口不改写，保存时输出归一后的位置。作者从温控器起画 HVAC 专用白色线管并连接内机控制端；红色电源线从强电箱起画并接内机电源端。控制线绘制模式只将可用的温控器源端和 FCU 控制目标高亮为绿色；强电箱起画且已有电源管草稿时，只将开放的 FCU 电源目标高亮为绿色。FCU 红色电源与白色控制端口均显示沿接口方向伸出的实体承口，端口模型本身可点击且从各视角保持可见；其他模式使用红色、紫色系统色，绿色只表示当前可连接。端口不叠加文字框；送风口/回风口文字仅在选中对应内机时显示。点击 FCU 目标会按现有目标端口规则连接；正交方向未对准时先确认辅助对齐点并提示继续绘制。每台温控器控制一台内机，FCU 电源端与控制端各最多接一根管。空调工具区提供放置内机、画风管（再由端口决定送/回风）、添加风口、放置控温器及画控制线操作；空调可见性由独立“空调”图层控制。

选中墙面控温器时，3D 与其他墙面点位一样显示所在面上、下、左、右四向的中心定位尺寸；各方向可输入净距，回车或失焦立即移动控温器。3D 控温器不叠加名称或端口文字，画管起点选择和控制线绘制模式显示未接线温控器的 8 个绿色候选孔；已连接后只显示所选紫色端口点，其他模式用紫色端口点，点击端口仍可选中控温器。属性面板仍显示并可编辑控温器名称。

画红色 FCU 电源线或白色 HVAC 控制线时，悬停可连接的内机接线口会按该端口的真实位置显示“连接后结束”或“辅助对齐”，并预览目标点或需先确认的辅助点；左键按同一方向规则确认，辅助点确认后可继续逐段接入。

## 项目与图纸持久化

同一楼层多张图纸时，当前画布新生成的尺寸、标注和手工引线归入默认施工图，其他图纸布局保持原样；零张图纸的项目可直接往返，首次保存持久图纸内容时才创建图纸。2D 手工测量只属于当前会话。

新建梁会同时写入 `Beam` 节点和所属 `Level.children`；删除梁会同时移除这两处记录。统一项目导出后重新导入可恢复梁，未编辑的其他建筑节点仍保持只读。

当前梁编辑以垂直梁长边的物理面净距输入为准；梁体与端点不可直接拖动。下面关于 Beam 的持久化说明沿用同一规则。

梁的选择编辑采用点位同款的场景物理尺寸线：不能拖拽梁体或端点；场景只显示一条垂直于梁长边、从梁侧面沿该横向射线到首个墙实体表面的定位尺寸。沿 X 轴的梁显示 Z 向净距，沿 Z 轴的梁显示 X 向净距，斜梁显示“垂直梁净距”；墙本身可以倾斜，但不会取墙中心线、墙端、相邻梁或沿梁方向的距离。面板对应数值以 5 mm 精度整体平移梁，不改变长度或角度；找不到相交的墙实体表面时该字段不显示。Pascal 源墙缺少或为 null 的厚度时，渲染和梁吸附都使用 100 mm 默认实体厚度。宽度不会再改变任何端点操纵器，因为梁没有端点操纵器。

项目 JSON 顶层 `pascalConduitProjectId` 是 Demo 的稳定身份扩展，首次导出可写项目时生成一次；内容 SHA 仅标识某个修订版。统一 Project JSON 一次导出建筑、施工系统与图纸：支持原生“保存为”的环境会让用户选择位置并修改建议文件名，项目默认建议为 `*-export.json`，且不会原地覆盖导入源文件；不支持时才回退到浏览器下载。导入相同项目身份的新修订会保留并重验 Overlay，导入不同身份会建立新 Overlay；内部编辑仍跟踪建筑和施工更改，任一未保存时关闭或替换工作区会提示。所有导入建筑节点仍为只读，唯一例外是文档化的 Demo `beam` 扩展：3D 可从 Ceiling 下表面创建直线矩形梁，并以名称、截面、长度及真实墙/柱/梁表面捕捉和物理面净距字段按 5 mm 精度编辑；梁体与端点不可直接拖动；其底面、侧面和端面可承载明装管线和全部当前点位（顶面不可选且梁面不生成槽）；从墙面继续绘制时，明确命中的梁面会优先成为下一落点，并在正交锁定时以受约束方向与梁面求交；不能相交时，单击确认当前墙/天花上的辅助对齐点，随后可继续逐点转向梁面；设备几何和端口按所选梁面定向。编辑梁保持既有设备与管线的世界坐标，只清除不再接触梁面的宿主关系，不自动重连、拉伸或改线；仍承载设备的梁拒绝删除并显示设备身份，解除宿主后删除只清理其穿孔。有效梁实体对表面、悬空和世界轴向管线执行独立的阻塞碰撞检查；项目 JSON 保留 Level/Ceiling 关系和明确或 2700 mm 推导的标高依据；Overlay 从不承载梁几何。Beam、设备与穿孔记录只是 Demo 作者信息，不判断荷载、配筋、安全开孔区、规范合规或结构审批。

3D 点位测量仍从实际设备中心、86 盒下边缘或强弱电箱外壳边缘量取，尺寸的 endpoints、实体目标与编辑规则不因显示整理而改变。墙面设备选中时，H01 偏差和左右定位读数以小号物理文字贴在实际墙面；墙角、洞口或墙端的垂直见证线只标一次，文本靠近对应尺寸线，遮挡按墙体深度处理。属性主区保留 H01 偏差和左右参考；完成面高度只读显示，楼板顶/模型楼层及墙顶实体净距默认折叠。其他宿主继续显示现有四向定位和独立标高/实体净距；无 H01 时保留可编辑且按实际楼板顶面或模型楼层基准命名的垂直距离。设备/peer 的真实目标名称、测量 basis、witness 和 source IDs 保持不变。

烟感也按圆盘外壳计算下缘标高和点位射线命中，默认直径 60 mm、厚度 30 mm；不会把 60 × 60 × 30 mm 参数误当成方盒外廓。安装参考平面上的烟感预览同样按其合法宿主能力显示。

梁工具从真实墙面吸附起画，梁顶与起点墙顶齐平；终点必须吸附同层、同顶标高的墙、柱或已有梁面，不支持悬空提交或通过 Ctrl 绕过高度冲突。确认起点后，半透明梁体实时跟随鼠标，未吸附时显示红色且不可提交，合法吸附时显示蓝色；画梁不再显示或依赖辅助面；Shift 切换正交，第二次点击或 Enter 确认当前合法端点。新梁保存墙顶标高依据与两端支承面的稳定对象引用；旧 Ceiling 标高梁继续原样读取、保存，已有对象不自动移动。点位及空调放置继续保留独立的 Layout reference plane 与高度设置。详见 [Demo Beam 作者工具](docs/beam-authoring.md)和 [ADR 0016](docs/adr/0016-wall-supported-beam-authoring.md)。

同一 Layout reference plane 也服务于所有允许 Ceiling 安装的点位的新水平预览与放置；点位保存的仍是独立的 Installation reference plane 关系，而不是一个虚构的 Ceiling/Layout 宿主。隐藏共享平面不会移动现有点位，并会提示作者改用可见的合法实体宿主；墙面专用设备的宿主规则不变。

在放置普通点位、空调内机、风口或控温器时按 `Esc` 会结束当前放置模式、返回选择模式并清除悬停预览；此前已提交的点位保留。此操作不改变画管期间按 `Esc` 逐点撤回的行为。

锁定世界 X/Y/Z 轴绘制时，鼠标指向墙体、梁面或 Ceiling，会自动将端点吸附到该轴与实际有限面的交点，轴方向保持不变。平行、交点落在面外或洞口内时，只显示辅助对齐提示，继续在原轴上绘制；不把无限延伸的平面当成实体面。悬停预览、左键确认和完成路径共用同一计算，真实到面点保留对应宿主和局部坐标，辅助点不虚构宿主。普通线管、分支、消防信号/水管、HVAC 控制管及送回风管均使用这套规则。

画管仍由用户逐点确认：`V` 选择，空格临时平移视角且保留草稿，Shift 控制宿主面正交，方向键锁定世界 X/Y/Z，Enter 只完成已确认的点。按一次 Esc 撤回最近一个左键确认的点，再按可逐步撤回到起点；Esc 在画管会话中优先于已聚焦控件处理。吸附候选仅包括兼容设备端口、开放管端、合法分支位置和宿主边角；悬停设备后左键点击具体端口孔会以孔的实际位置选择正交方向，点击设备本体则按悬停位置选择方向。约束不共线时，点击会确认辅助对齐点，继续画管而不建立虚假连接。分支绘制复用同一套目标确认流程：左键确认辅助点，再点击兼容设备的开放端口连接并结束；创建分支后点击主管不会重新创建分支。世界 XYZ 锁定时，点击梁仍确认受轴约束的预览点，表面拾取不会覆盖轴锁；普通管线、分支、消防及 HVAC 绘制遵循同一优先级。从 86 底盒续画也可用同样方式抵达并连接目标设备端口。本 MVP 不提供数字管长输入或自动布管。

## 2D 施工图画布

建筑画面采用 Builder 的白色画布、深色墙体和浅灰楼板，施工图专业表达继续保留。右键、中键或空格加左键拖动平移；左键用于选择、测量和标注。右键单击仍取消未完成手工测量。纵向滚轮和捏合按指针位置缩放，纯横向触控板滚动平移。

管段挂载设备的 2D 符号、定位尺寸与标注共用世界坐标和挂载语义，喷淋头不会被加入墙面尺寸链；室内轴向尺寸保留真实见证与已有数字位置、线偏移。

2D 测量、建筑/施工图层、标注、对象隐藏与属性检查集中在可调宽或隐藏的常驻左栏「图纸」标签，画布内不再悬浮 2D 操作面板。底图采用黑灰线稿，家具素材保留细节并灰度淡化；设备使用以真实中心为锚点的符号，管网按系统着色。墙插保留半圆墙装符号，楼板顶面挂载的地插使用独立的方框、内圆和双孔俯视符号，图例同步呈现。普通 Overlay 点位（墙插、地插、吊顶点位、开关、灯位接线盒、网络及消防点）统一量到点位中心，边界统一取同方向首个实体墙面或洞口边，绝不取墙轴线；缺省墙厚由共享的 100 mm 默认值提供。强电箱和弱电箱的水平定位尺寸从真实外壳边缘起算，尺寸线延长端点也落在该边缘；对应 2D 箱体图块沿墙的长度和进深分别使用 `device.sizeMm[0]` 与 `device.sizeMm[2]`，不随点位标注比例缩放。内机、梁和风口等有实体外廓的施工净空对象也量到实体外边，直风管保留端点长度尺寸。2D 与 3D 共用有限实体表面的射线命中和设备外壳几何，分别负责尺寸链布局与场景标注。墙面定位尺寸链会命中首个相接墙房间侧实体面、洞口边或墙端，并保留物理见证点及来源对象；图上的尺寸线投影和实体见证分开保存。点位 H 标注从实际 3D 外壳的世界 Y 下缘减去点位投影处楼板顶面，无楼板时回退到楼层基准；参考平面灯位接线盒也按圆盘厚度取下缘，设备中心位置和既有 mount 中心标高字段继续原样保留。毫米模式下，所有 2D 尺寸线数字均不附加 `mm` 后缀。网络线路仅在 2D 显示为深灰，3D 和保存颜色不变。

左栏「图纸」标签分为“建筑图层”和“管线图层”，可分别开关墙体、梁、楼板、门窗、楼梯、家具、空间名称、外围尺寸，以及插座、照明、网络、消防管线和点位图块。梁只显示可选择的灰色足迹，不提供 2D 编辑或永久尺寸文字；其透明视觉面位于施工对象之上，但不抢占设备和管线的点击。左栏不展示开发统计或解析诊断。点位标注显示设备类型或人工设备说明及 `H=离地高度`，不显示生成编号，也不标注管径、管道上行/下行、方向或墙端定位。双击设备说明可编辑现有 Overlay 的 `device.name`；高度、数量和排列关系继续由模型生成。

2D 空调图保持只读，并由施工图层内独立的“空调施工图”总开关控制：显示内机、送风/回风矩形风管、风口、控温器、控制管线和实际电源管线。内机外廓、送回风端口宽度、矩形风管平面宽度、风口位置和控温器 86 mm 外廓均直接投影自同一份 3D 模型尺寸；蓝色“送”和橙色“回”位于内机端口色块内。控温器沿用墙面点位的标高说明和定位尺寸；内机从外壳实体边缘量至该方向首次命中的墙体实体面，直风管显示实际端点长度，风管截面以可拖动的“送风管/回风管 W×H mm”说明框表达。

房间文字、尺寸数字、测量数字、点位图块和点位标注均使用模型空间尺寸，随图纸缩放保持相对比例；旋转时文字保持正向。“点位标注比例”默认 50%，可在 50%–200% 间全局调整点位符号和点位文字；强电箱、弱电箱图块的真实外壳尺寸不受该比例影响。同墙相邻中心距离不超过 150 mm 的点位自动组合：同类型同高度合并数量，水平组合显示左/中/右，重合投影的不同高度组合显示上/中/下。说明块按最近建筑外围边放在外围尺寸之外，使用两排主引线、竖向主干和逐行分隔线。

“点位图例及安装高度表”以底部主操作栏上方的折叠入口提供，默认收起；点击后向上展开并可滚动，不长期覆盖图纸或被主栏遮挡。右下角的“图纸提示”汇总未能生成的尺寸链等图纸问题；例如“该方向定位尺寸链未闭合”只表示该点位的一部分定位尺寸缺少可靠参照，设备本身仍可在 2D 和 3D 显示，不代表重复点位。

自动点位标注面板、手工引线、点位定位尺寸的数字位置，以及尺寸线的法向偏移都保存在统一 Project JSON 的 Drawing 节点；内部 Overlay 只是编辑快照。自动点位标注和定位尺寸首次显示时即锁定分组、横竖排、行顺序、文字框位置、尺寸数字位置与尺寸线偏移：3D 单纯改高度只更新 `H=` 值，不重组标注或重算既有定位尺寸链的绘图位置；新增点位只补充相关的新记录，不覆盖已有图面布局。一行内多个点位的高度不再相同时，该行保留并列展示这些高度。删除点位、改变其平面宿主/类型/系统或使其加入、离开该组时，只有受影响组才重新派生；不再派生的标注不会显示。点击点位定位尺寸线或文字框即可选中并高亮；点击 2D 空白处或按 `Esc` 取消选择。按 `Delete`/`Backspace` 只隐藏选中的派生 2D 尺寸或标注，不影响 3D；该显示决定保存到 Drawing，支持 `⌘/Ctrl+Z` 撤销和 `⌘/Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。按住点位定位尺寸数字，沿实际尺寸线拖动即可移动数字；垂直尺寸线拖动可移动整条尺寸线及其见证线。尺寸线只对同方向的其他点位定位尺寸线吸附，不参考建筑外围尺寸、墙体或点位；进入 50 mm 范围时吸附，拖离 70 mm 后释放，并以高亮反馈当前对齐对象，避免缩放改变吸附手感。

## 完成面定位面

确认水平基线离完成面的高度后，自动在真实楼板范围内生成可见、可选、可吸附的完成面定位面，保留楼板孔洞及明确 Zone 高低差；墙上同步显示与水平基线样式一致的完成面高度线，贴墙标注“地面完成面”，跟随明确 Zone 高低差并在门窗洞口中断；不修改导入建筑几何。新地面底盒默认上口齐平、盒体向下埋入，属性显示上口相对完成面的实际偏差。旧点位不会随完成面改高自动移动，可通过明确的“对齐完成面”动作调整，已连接设备遵守移动锁。

选中地面点位时，四个方向中有真实墙面见证的中心定位尺寸与高亮地面参考线使用相同 G 编号，面板写“中心至 G01 基准线”等；不显示 H01 的竖直偏差或下缘到原始楼板的安装字段。水平基线两侧按真实墙体斜接面边界收口，避免墙角处缺线或多线。墙面垂直基准沿有效墙高通长高亮，墙角沿安装侧的真实表面交界棱；宿主墙自身端部也使用实际斜接边界，距离读数、距离编辑与高亮尺寸端点保持一致。完成面设备挂载与测量证据随统一 Project JSON 保存，详见[施工基准合同](docs/construction-datum.md)和[ADR 0015](docs/adr/0015-derived-finished-floor-placement.md)。

3D 对象选中外观对齐 dsphere Editor：保留原材质并混入 32% 的 `#818cf8` 蓝紫色，加入同色 70% 的自发光混合与 0.42 强度；半透明对象选中时透明度最多增加 0.08。建筑、梁、点位、管线及 HVAC 共用这一配方，定位尺寸和绘制预览继续保持各自颜色。此效果只影响显示，不写入项目材质或系统颜色。
