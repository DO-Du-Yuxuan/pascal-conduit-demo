# Pascal 施工管线路由 Demo

这是独立的管线编辑 Demo。它以 `pascal-layout-auditor` 的 Parser、二维画布和只读 3D Viewer 为底座，但不展示、不运行或写入任何 G1/G2/G3/G4/S1 评价结论。

默认建筑底图是用户提供的 `sample-data/default-layout.json`，SHA-256：`32d135bef65a6a0fdb06485cc24a68a68cd864e9a4322907971c659b26c7e167`。它默认加载且 Overlay 为空；不再使用 Bellevue 作为 Demo。

## 保留的 Viewer 能力

- 原始 Pascal JSON 宽容解析、解析诊断、二维多画布、楼层切换、旋转、平移、缩放、测量、图层和对象隐藏/恢复。
- 支持纯 2D、纯 3D 与可拖动的 2D+3D 分屏；分屏左侧使用当前第一个 2D 画布，切换视图不会重新解析底图或清空 Overlay。
- 3D 外观、室内、地板、天花，以及顶/前/后/左/右/等轴视角。
- 3D 相机只保留世界地面的轻微边界缓冲；墙、天花、家具、管线和隐藏节点均不作为相机碰撞体，可直接穿过。
- 透视/正交、叠放/爆炸/单层、完整/剖开/半透明/隐藏墙体、建筑与四类管线图层。
- 墙、弧墙、门窗洞口、楼板厚度、天花、楼梯、屋顶数据和家具尺寸占位。无 roof 数据时明确提示，绝不虚构屋顶。

## 管线 Demo

- 强电：红色 `#ef4444`，20 mm；弱电：蓝色 `#3b82f6`，20 mm；信号：白色（灰描边），20 mm；消防喷淋：绿色 `#22c55e`，50 mm。
- 3D 是唯一绘制入口。画管默认开启宿主面正交，左键选择/落点，右键旋转，中键平移，滚轮缩放；`Shift` 点击切换宿主面正交，方向键切换世界轴悬空走管并关闭正交；双击或 `Enter` 完成，`Esc` 取消最后一点。
- 直管、圆角大弯、三通、直接接头、86 检修盒、墙/楼板浅槽和穿孔保存在独立 Overlay sidecar。2D 只读显示同一份端口化管网，可选择但不可编辑。
- 2D 只显示管线连续几何和 86 地盒符号，不为弯头、三通或直接接头额外绘制节点圆点；3D 三通按三个物理端口显示圆筒承口。
- 在 2D+3D 分屏中，3D 的起点、实时中心线、圆角大弯、分支地盒和冲突红色状态会同步预览到 2D；临时预览不写入 Overlay，也不产生撤销记录。
- 分支模式沿已有管段实时预览分支点；红、蓝、白系统插入同色 `86 × 86 × 50 mm` 检修盒，消防系统插入三通，随后继续使用普通画管交互。
- 四类系统均按 4000 mm 最大中心线定尺自动插入直接接头。红、蓝、白线管只要中心线发生非共线转向，就统一使用默认 200 mm 相切大弯，不再区分同宿主、跨宿主、多次换面或 Tab 穿透；净空不足时禁止落点和提交。消防继续使用标准弯头。
- 四类管线实体均不得交叉；冲突草稿显示红色并禁止左键落点、双击、Enter 或“完成路径”提交。共享同一物理端口的接触不算冲突。
- Tab 会冻结按键前最后一段的入射方向，沿同一直线穿过入口宿主；出口确认后重新附着实际目标宿主，并恢复 Tab 前的宿主面正交状态。普通自由/正交模式始终依附宿主面，只有世界 X/Y/Z 模式允许悬空走管。
- 施工态和 X-Ray 在运行时展示电气线管作用于墙体、楼板顶面的直线与圆弧浅槽，以及独立的贯穿孔；天花和消防不生成浅槽。完工态恢复建筑饰面并隐藏暗敷电气线管。切割失败时保留 Overlay 和同尺寸替代槽线，并在左侧面板提示。原始 Pascal JSON 永远不被修改。

墙/楼板浅槽宽度默认是管径 + 10 mm、深度是管径 + 5 mm；穿孔直径是管径 + 10 mm。大弯半径 200 mm、定尺 4000 mm 与槽孔尺寸均是可编辑的 Demo 参数，不是施工规范结论。消防喷淋默认吊顶内明敷，不生成浅槽。

## 运行与校验

```bash
npm install
npm run verify:sample
npm test
npm run build
npm run dev
```

浏览器视觉验收由用户执行；自动化流程不启动浏览器、Playwright 或 CUA。
